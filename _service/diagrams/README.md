# Галерея эталонов схем

Образцовые схемы, собранные библиотекой `pptx_diagram.py`
(`_service\skills\universal-pptx\scripts\`). Каждая папка — самодостаточный
пример: `build.py` (пере-собирается в `example.pptx` рядом; в 05 — `plan.json`,
собирается `deck.py build`) + `preview.png` (утверждённый вид, пересоздаётся
рендером). Брать как основу для однотипных слайдов, менять узлы/связи/подписи.

Рисование — нативными фигурами pptx: заказчик правит текст в PowerPoint.
Семантические роли окраски (`node(role=...)`): app / data / model / people /
plain / planned — цвета берутся из **активной темы** (theme.json), по умолчанию
`minimal`; тема задаётся env `DECK_THEME` перед запуском build.py.

## Этапы

1. `01_крупноблочный_обзор\` — архитектурный крупноблокный обзор для
   руководителей (контейнеры-периметры, узлы app/data/model, «ёлочка» в обход
   блока, пунктир аутентификации, легенда).
2. `02_последовательность\` — UML-секвенция `sequence()`: актёры, линии жизни,
   ответы пунктиром, серые заметки, alt-ветвление; рядом колонка-вывод.
3. `03_алгоритм\` — вертикальный флоучарт `flow()`: start/proc/io/dec/end,
   QA-гейт ромбом с возвратом «нет» на пересборку.
4. `04_схема_подключений\` — схема сервисов/подключений из mermaid: `diagram.mmd`
   разбирается `mmd2diagram.py` (периметры из subgraph, формы и роли узлов,
   пунктир, метки в чистых зонах). Сквозной путь mermaid → нативные фигуры pptx.
5. `05_плотная_архитектура\` — ПЛОТНАЯ схема (17 узлов, 5 периметров): колоночные
   ланы, свободные коридоры разводки, ортогональные связи явными точками (без
   from/to) с входом в грани снаружи, кегль 9/7, qa 0/0. Источник — `plan.json`
   (декларативный блок `diagram`). Правила — SKILL.md «Плотные схемы».

## Импорт из mermaid (mmd2diagram.py)

```
python _service\skills\universal-pptx\scripts\deck.py mmd diag.mmd              # json-блок diagram для plan.json
python _service\skills\universal-pptx\scripts\deck.py mmd diag.mmd --emit py    # каркас кода для build.py
python _service\skills\universal-pptx\scripts\deck.py mmd diag.mmd --preview out.pptx --title "…" --legend "solid=запросы,dash=wi-fi"
```

Поддерживается flowchart LR/RL/TD/BT, subgraph (вложенные), формы
`[..] (..) ([..]) [(..)] {..} [/../]`, связи `--> --- -.-> ==>` с подписями,
роли классами `id:::data` / `class a,b model`. РАСКЛАДКА — КАРКАС: после сборки
обязательны qa + рендер + визуальная проверка и доводка меток. Секвенции и
линейные алгоритмы верстать сразу `sequence()`/`flow()`.

Для простых схем без ветвлений есть декларативный тип блока `diagram` в
plan.json (см. докстринг `plan.py`).

## Как собрать пример

```
python _service\diagrams\01_крупноблочный_обзор\build.py
python _service\skills\universal-pptx\scripts\deck.py qa _service\diagrams\01_крупноблочный_обзор\example.pptx
python _service\skills\universal-pptx\scripts\deck.py render …example.pptx -o …\render
```

## Правила (подробности — SKILL.md `universal-pptx`, раздел «Схемы»)

- метку связи ставить в межблочный зазор ≥ 2 см или внутрь контейнера, не на рамки;
- одиночные пересечения пунктира с сплошными допустимы, сплошная×сплошная — нет;
- qa проверяет «связь сквозь текст» — после каждой пересборки смотреть WARN;
- сетку рядов/колонок считать `row_tops()/col_lefts()`, а не в головах.
