# Фабрика презентаций «для всех»

Универсальная фабрика презентаций для ИИ-агента: школьный доклад, реферат,
курсовая, диплом, лекция, рабочий отчёт, питч. Не корпоративная — вместо
брендбука набор тем оформления. Любой агент (OpenCode, Cline, Codex, Copilot и
др.) читает правила в `AGENTS.md`, берёт тему из `_service\themes\` и собирает
презентацию по стандартному циклу: план → сборка → аудит → рендер → проверка
каждого слайда глазами.

## Что нужно сделать человеку

Вариант 1 — **есть материалы** (конспект, реферат, docx, заметки):

1. Создать папку и положить в неё материалы.
2. Сказать агенту: «сделай презентацию по материалам из <папка>».

Вариант 2 — **материалов нет, есть только тема**:

- «сделай презентацию про круговорот воды, 8 слайдов, для 6 класса»;
- «подготовь слайды к защите курсовой по файлу <файл>, строгий стиль».

Можно указать тему оформления: «в тёмном стиле» (dark), «строгую/академическую»
(academic), «простую светлую» (minimal — по умолчанию). Можно попросить
дополнить материалы данными из интернета — иначе агент работает только по
тому, что дал человек, и честно помечает догадки.

Результат — `<Имя_Проекта>.pptx` в папке проекта; служебное (план сборки,
превью) агент складывает в `_build\`. Все числа на слайдах проверяются по
`_build\facts.md` — выдуманных фактов фабрика не разводит.

## Устройство (для агента / разработчика)

- `AGENTS.md` — единственный источник правил: структура, режимы входа («из
  материалов» / «из темы»), приоритет темы оформления, дисциплина фактов,
  рабочий цикл, единицы, язык. Заглушки `CLAUDE.md`, `.clinerules\00-agents.md`
  ссылаются на него.
- `_service\themes\<тема>\` — темы оформления: `theme.json` (палитра, шрифты,
  сетка) + `template.pptx` (генерируется из theme.json: `deck.py make-template`)
  + `inspect.md`. Стартовые: **minimal** (светлая), **dark** (тёмная),
  **academic** (строгая, с засечками), **book** (книжная A4-полоса, портрет).
- `_service\skills\universal-pptx\` — скилл: `SKILL.md` (процесс и грабли) +
  `scripts\deck.py` (CLI: themes/build/mmd/qa/facts/dump/check/render/thumb/
  make-template).
  `.opencode\skills\`, `.claude\skills\` — junction-ссылки на него.
- `_service\` также: заготовка `build.py`, `fonts\` (Inter), `diagrams\` —
  галерея эталонов схем нативными фигурами.
- `<Имя_Проекта>\` — папка презентации: материалы где лежали, рядом готовый
  pptx и `_build\` (plan.json/build.py, facts.md, render\slideN.png).

## Быстрая проверка, что фабрика жива

```
python _service\skills\universal-pptx\scripts\deck.py themes
python _service\skills\universal-pptx\scripts\deck.py build Пример_Солнечная_система\_build\plan.json
python _service\skills\universal-pptx\scripts\deck.py qa  Пример_Солнечная_система\Солнечная_система.pptx
```

Зависимости: `pip install python-pptx lxml Pillow matplotlib`; рендер на Windows —
PowerPoint (COM), вне Windows — LibreOffice.
